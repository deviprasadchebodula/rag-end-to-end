# Contributing

Suggestions and bug reports are welcome.

1. Fork the repository and create a feature branch.
2. Configure your own local credentials using .env.example.
3. Make a focused change and run Python syntax checks.
4. Test affected functionality with a non-confidential sample PDF.
5. Open a pull request describing the change, validation and limitations.

Never commit credentials, uploaded documents or generated model caches. Do not introduce paid cloud resources or live deployment automation without explicit approval.

Please report security issues privately as described in SECURITY.md.
